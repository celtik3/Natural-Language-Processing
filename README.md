# Natural Language Processing – Spring 2025  
**Course:** DS680-102 at NJIT

This repository contains the final Spring 2025 Natural Language Processing course project at NJIT. Our team developed a Retrieval-Augmented Generation (RAG) system for scientific question answering using large language models (LLMs) and a curated arXiv knowledge base.

> ⚠️ This is a fork of the original repository by [@joshuakobuskie](https://github.com/joshuakobuskie), where we originally hosted the project. I contributed to this project as a core team member.
